# Ace Combat Wizard
This application automates the modding process of Ace Combat 5 and Zero.
It is intended to be a substitute for AC4Analysis.

## Intended Features:
1. Hands-off packing and unpacking of game files - IN PROGRESS


1. Documentation and annotation of game files and assets
1. Visualization, conversion and exporting of multiple asset types
    - Images and textures
    - 3D objects
    - Text
    - Sound

1. GUI for intuitive interaction
1. CLI for automated workflows and pipelines
